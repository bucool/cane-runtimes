# Slider v1 映射的独立推导与保留边界

## 功能需求和量纲

Slider 以手动时间或骨骼的一个标量属性选择目标动画的一帧，并按 mix 作为一层应用。
目标层不推进自己的时钟，也不生成目标事件；约束声明顺序决定读写先后。
这些是本产品保留的互操作和编辑行为，不以官方实现的语句顺序作设计模板。

设源标量为 u，源基准为 u0，目标时间基准为 t0，每单位源值对应 k 秒。
要求映射斜率恒定且 u0 映到 t0，则唯一仿射函数为：

```text
t(u) - t0 = k * (u - u0)
t(u) = t0 + k * (u - u0)
```

这来自直线的斜率定义，与动画产品无关。k 可负（反向）或零（常量）；u0 与 t0
不要求为零。已有三项映射参数足够表达该函数，不新增持久化字段。

自制解析例：u0=2、t0=1/4、k=1/8 时，u=6 映到 3/4，u=-2 映到 -1/4；
k=-1/8 时 u=6 映到 -1/4。k=0 时所有可用源值映到 t0。

## 数值域与本次修正

源值及参数须有限。保留 v1 的 binary32 减法、乘法、加法次序；不改成隐藏的
双精度/FMA 语义。非零斜率下，减法或乘加产生非有限结果时，本次 Slider 不提供
目标层或有效采样诊断。这是既有 v1 的 unavailable/no-op 约定，不是新的异常隐藏策略。

有限性必须在循环/钳制之前判断。无穷值被 clamp 变成端点，不代表计算结果有效；
错误的端点采样也可能改写骨骼、附件、约束等，必须阻止。零斜率先由函数定义化为
常量 t0，不计算无用的 u-u0，避免有限两端相减溢出后出现 infinity*0。

这两项是对已发布文档“非有限映射不可用”和“零斜率恒为 offset”的实现修正，
不引入新的 constraint feature 或最低 API minor。明确记录旧实际行为与新行为：

- 非循环且映射溢出：旧实现可能应用端点；修正后保留已有姿态，不应用这个 Slider。
- 源差值会溢出但 k=0：旧实现可能跳过常量层；修正后按有限 t0 正常采样。

这些边界修正需要自制回归验证；不能靠重新生成 Golden 来接受。

## 源属性保留依据

局部模式读已求解局部属性，以保证前序约束的输出可被后续 Slider 使用。
世界模式使用 `M = inverse(hostRoot) * boneWorld`；这是消除外部坐标系的普通换基。
设其 X/Y 轴为向量 (a,b)/(c,d)，原点为 (tx,ty)：

- 平移是原点坐标；尺度是轴向量长度，故使用 hypot。
- 旋转是 X 轴极角；v1 选择负角加 360 的表示区间。
- shearY 是 Y 轴极角减 X 轴极角再减 90 度；v1 保留该有向角差，不再折叠。
- 局部有符号尺度与世界轴长度属于不同定义，不因名称相同改成同一个量。

不可逆 hostRoot 时世界源不可用，局部源仍可读。共享 FK、根矩阵构造和逆矩阵
遵循统一仿射变换契约。
独立案例需覆盖换基不变性、镜像、剪切、零轴与奇异根，不能只覆盖单位矩阵。

## 时间边界与层应用的保留决定

循环使用现有 binary32 Euclidean remainder；非循环骨骼源钳至 [0,D]，手动时间
保留给普通通道采样器处理。D=0 时骨骼源为零、手动时间不变。
这两个入口及现有循环归一化调用次数属于保留的 v1 兼容选择，不声称数学必然，
也不在本次有限性修正中改变极接近周期边界的舍入结果。

Replace 是当前值到采样值的仿射混合；Additive 是当前值加上采样值相对 setup
的增量。复用统一动画采样器可使 Slider 与普通播放遵守同一通道语义；采样器
遵循曲线、通道投影与姿态组合规格。

每次外层求解只遍历有限的 N 条声明，每条读取当时定义的副本。目标层可以更改
后来声明的参数，但不递归调用约束循环。循环次数最多 N，因此自引用与环形
动画关系也终止。这一终止性证明不依赖某个特定产品的更新缓存实现。

## 验证门槛

1. 用常数和可手算直线验证锚点、反向、零斜率和任意有限 mix。
2. 先复现减法/乘法/加法溢出被钳到端点，再检查修正后的姿态和诊断。
3. 用真实公开 API 载入自制数据，检查有限帧、后续 apply 与配置不受误采样影响。
4. 保留并运行声明顺序、自循环/双向循环、局部/世界及固定帧量化的既有测试。
5. 对既有 suite 1.12.0 运行 verify；任何变化单独复核，不自动刷新 expected。
