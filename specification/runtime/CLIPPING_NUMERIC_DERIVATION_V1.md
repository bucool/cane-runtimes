# 裁剪几何的独立推导与数值修正

凸多边形是有向边半平面的交集。线段 P(t)=(1-t)P0+tP1 到同一条边的有向面积也是
线性函数，因此穿越边界时 t=d0/(d0-d1)，位置与 UV 用同一个参数插值。
依次求交即一般 Sutherland–Hodgman 方法。凹多边形采用不相交耳三角形分解；
[Eberly 的耳切说明](https://www.geometrictools.com/Documentation/TriangulationByEarClipping.pdf)
提供这一通用方法的背景。反向裁剪依次保留当前片段在各半平面外的部分，并从余下部分继续。
不将上游某种实现或旧规格的逐句伪代码当作新的创作依据。

## 需要修正的数值行为

多边形平移不能单独使面积变零或改变是否可裁剪。原先对绝对世界坐标作 binary32
shoelace 求和，平移到较大坐标后，大乘积相减会丢掉原本可精确表示的局部面积。
较大但有限的坐标还会使二阶乘积溢出。段插值中的 binary32 `to-from` 也可能溢出，
即使最终交点就在两个有限端点之间。

独立几何方案：

1. 选择多边形第一个点 O，以三角形 `(O,P_i,P_(i+1))` 的有向面积求和。
   由叉积双线性展开，所有 O 项相消，等于原多边形面积；计算不依赖绝对坐标原点。
2. 有向面积 `cross(B-A,P-A)` 的输入先由 binary32 精确扩展至 binary64，再相减和相乘。
   有限 binary32 坐标的这些乘积不会超出 binary64 范围。
3. 半平面距离、穿越参数与位置/UV 插值保持 binary64 中间值；输出位置和 UV 转回 binary32。
   比较阈值仍取原 binary32 常数精确扩展后的值，不能悄悄改变 CLIP_EPSILON。
4. 不改变耳选择次序、重复点政策、凸包政策、反向片段次序、索引上限或失败原子性。

这修复原几何功能的精度缺陷，不另建语义 profile。不承诺任意病态多边形的精确谓词，
也不能恢复在输入 binary32 世界坐标中已经丢失的细节。自交、近退化及容差带仍按原规则处理。

## 验证

先复现可手算矩形/L 形的平移面积、凸/凹及反向裁剪；使用可表示的平移量和顶点，
验证面积、UV 和片段存在性。另测大坐标乘积及相反端点的有限中点。
公开 Runtime API 验证实际裁剪后的几何，保留原正式案例、答案与容差；不能只测 helper。
