# 动画采样失败与事务边界

连续采样使用 [roots-v2](ANIMATION_CURVE_ROOTS_DESIGN_V2.md)。无生效关键帧与采样错误
必须可区分，不能将非有限结果当成颜色端点、零值或缺失关键帧。

## 错误传播

骨骼、明暗颜色、图片 alpha、附件姿态、变形及约束参数均传播采样错误。
没有参与求值的零权重或离散门槛关闭的通道不触发数值计算；必要的通道存在性仍须保留。
颜色范围约束、整数转换和变形发布均在错误检查之后进行。
错误包含动画和目标身份，使用 `animationCurve` 字段标识失败通道。

## 原子发布

采样、通道投影、姿态组合、约束、事件及最终几何全部成功后才发布帧。
失败保留调用前的姿态、时钟、队列、Physics 历史、配置、统计、事件与帧序号。
Slider 目标动画的采样错误同样向外传播，不跳过失败图层。
Physics reset 的触发身份和最终皮肤规则见 [条目求值](TRACK_ENTRY_EVALUATION_V2.md)。

## 验证要求

有限关键帧与极大有限控制值应覆盖每类通道的不可表示结果；同时验证零权重、阶梯、
端点和同时间关键帧。失败后恢复采样的结果须与未执行失败操作的实例一致。
公开 `advanceTime`、`apply`、`advance`、`sampleAt` 和 Slider 路径均遵守相同事务边界。
