# 采样操作预算与事务

本规格接续 [静态准备与 Slider](TRACK_PREPARED_SAMPLING_V2.md)。

## 单一操作额度

采用可复制、可比较的显式计数器，记录限额、剩余额度和各阶段的已用单位。
使用 checked 加减乘；溢出与不足均明确失败，不能饱和为一个看似合法的数量。
阶段为 setup 准备、轨道图、timeline 输入、投影、组合、实例解码/发布、reset 和
Slider 当前姿态。单位用于结构性工作准入，不是 CPU 指令数、字节内存上限或毫秒。

数据文件读取、CaneData 原有构造/验证、通用事件派发、其他约束求解和渲染各有自己的
边界，不由这个采样计数器声称控制；Physics 固定步预算继续独立存在。

按以下规则在工作或动态分配前收取额度：

- setup：静态记录的固定字段、标识字节、可变几何/权重/皮肤成员；不可变 schema 缓存
  保存本次准备的结构成本。冷热使用收取相同的逻辑准备成本，不依赖先运行过哪项测试。
  不足时不建立缓存中的失败条目；增加额度后可重试同一个数据对象。
- 轨道图：遍历轨道槽和实际可达中断链前计数；已被进度 1 截断的旧动画、进度 0
  不参与求值的新动画不解析值。透明轨道仅构建 presence，不能因预算层求值坏曲线。
- timeline：关键帧、曲线描述、字符串、变形坐标、排序成员及原始约束 JSON 在解析、
  求值或克隆前计入。输入按借用方式扫描；嵌套结构采用迭代访问和明确深度上限。
  全局 Physics 目标展开和附件查找等乘积工作用 checked 乘法计入。
- 投影/解码：通道、标识、离散字符串、向量和排列按实际规模计入，完整 pose 的
  稀疏索引存储也计入。现有纯组合器继续按其验证、复制和求值的实际计数扣除**同一份**额度。
- reset：先检查主轨道门限和时钟区间；原始约束解析、key 检查、目标扫描和活性判断
  计入，仍只报告去重的 reset ID；不按循环次数逐圈分配。
- Slider：每个实际执行的图层从当前剩余额度继续，当前姿态捕获、目标采样、组合、
  解码及附件重建一并计入。不能给每个 Slider 重新发放整份限额。

输入规模准入是保守计算；固定次数的数学、容器常数因子与已有曲线内核的独立迭代上限
不等同于逐指令计数。规格与报告应明确这一点，不作任意工程硬实时或总进程内存保证。

## 发布与重复求值

单次采样先对预算和中间状态的副本求值，成功后同时发布实例、主轨道时钟身份和预算。
随后世界求解的多个 Slider 使用保存的剩余额度；既有整实例 clone/commit 也覆盖该预算。
增加一个整帧入口，接收调用方持有的采样及 Physics 预算，在 detached 实例上完成
采样和世界求解后一起提交。相同调用方预算可连续用于多个帧/重放步骤，不能每帧自动
重置；失败保留调用方两个预算、实例和时钟身份。

## 验证要求

保留既有手算及精确分数答案，不从新实现生成数学期望。新增测试必须证明：

1. 冷准备额度不足后同一对象可重试，热缓存不降低准入成本；
2. 很大的关键帧/变形/raw JSON 在解析/采样前拒绝，透明和不可达动画不意外求值；
3. 一个 Slider 可完成而同额度下两个 Slider 因累计开销失败，整实例状态完整保留；
4. 多帧共享操作预算、不足后的重试、以及最后一个 Slider 的曲线失败均为整帧事务；
5. reset、长标识和不同阶段的工作均真实计入；成功输出仍满足原有独立答案。
