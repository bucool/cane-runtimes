# 蒙皮与变形反解的独立数学依据

2026-09-24，先记录需求，再修正实现。这里只处理运行时几何和编辑查询使用的纯数学，
不把 UI、命令、撤销或导入导出移入 runtime。

## 可保留的数学与坐标契约

线性蒙皮把每个骨骼变换后的点按权重组合。独立的公开背景资料为
[Khronos 的蒙皮教程](https://github.khronos.org/glTF-Tutorials/gltfTutorial/gltfTutorial_020_Skins.html)：
它说明骨骼当前变换、绑定逆矩阵及加权组合之间的关系。Cane 的二维矩阵和数据表示不同，
以下给出对应的二维线性代数推导。

对一个顶点，令归一化正权重为 p_j，当前骨骼线性变换为 L_j，绑定逆矩阵的线性部分为 B_j。
显式骨骼局部坐标的变形增量使用恒等映射；通过绑定逆矩阵表示的增量使用 B_j。
当所有 influence 共享一个编辑增量 d 时，世界位置变化为：

`worldDelta = sum_j(p_j * L_j * C_j) * d = M*d`，其中 C_j 为 I 或 B_j。

原有各 influence 的 offset 可以不同。对当前世界位置到目标位置的差解出同一个 d，
再给每项增加 C_j*d，即保留原 offset 差异和作者编辑的坐标含义。
绑定逆矩阵的平移只作用于点，不能作用于这个增量。零权重项仍占其声明的 offset 位置。
皮肤有序覆盖、linked mesh 的几何/变形两条引用链属于单独的数据解析契约，不混入此方程。

## 非奇异二阶线性反解

M 写作 `[a c; b d]`，目标差为 `(u,v)`。消元给出：

`det = a*d-b*c`，`x=(d*u-c*v)/det`，`y=(a*v-b*u)/det`。

是否有唯一解取决于 det 是否为零，与像素单位或整体缩放大小无关。
既有 Geometry 规范明确说矩阵奇异性不使用 EPSILON；本次发现三个变形反解分支仍用
绝对 EPSILON，因而把 `diag(2^-12,2^-12)` 等可逆变换错误拒绝。
另一个先构造 binary32 逆矩阵的权重位置查询会因中间行列式溢出/下溢而失败。

采用共享的二阶求解内核：输入的四个 binary32 系数精确扩展到 binary64，差量在
binary64 中相减、求行列式和消元，不先生成必须能装入 binary32 的完整逆矩阵。
最终坐标或 offset 加法完成后才转回 binary32，并检查有限性。
这是对既有非奇异定义和可表示结果的修复，不新增动画 profile，不改变权重归一化或正向蒙皮政策。

## 失败与边界

- 精确零行列式继续失败，即使某个目标可达；本接口没有唯一解选择或伪逆政策。
- 非有限输入、最终结果超出 binary32、无权重数据或绑定资料不完整继续返回失败。
- 镜像的负行列式是有效输入；统一缩放不能单独改变是否能编辑。
- 返回 owned 查询结果，输入数组、播放器帧、时钟和待发事件保持不变。
- 本阶段不声称解决所有高条件数、正向加权累加溢出或浮点矩阵乘法问题；这些仍需独立核查。

## 独立验证

使用自制数据验证可手算缩放/镜像、很小/很大尺度、精确非零但 binary32 乘法会
相消的行列式、绑定逆矩阵的空间往返、保持 influence offset 差异、真正奇异与超范围失败。
先用原生产路径复现，再通过共享内核修复；保留原正式夹具与容差，不批量刷新答案。
既有皮肤和 linked mesh 用例继续保留，新测试不能取代真实编辑器操作验收。

## Path 与共享加权计算收尾（2026-09-24，先于实现）

Path 的顶点世界目标与骨骼局部坐标查询应与其它顶点附件使用同一个反解契约，
保留 Path 控制点布局检查后委托公共入口，不继续维护另一份行列式、绑定增量
矩阵和完整逆矩阵。零权重项仍占索引，局部坐标查询仍按所有声明 influence 的
顺序返回；奇异/超范围/缺少引用继续失败，查询不能改变发布帧或输入。

对已算出的有限世界点 R_j，归一化组合为 `sum(w_j R_j)/sum(w_j)`。
有效行允许权重和在 `1±0.001`：如果所有 R_j 等于 binary32 最大有限值，
权重和略大于 1，先按 binary32 求和会溢出，但正确平均值仍等于 R_j。
因此加权乘积、累计和除法使用 binary64，仅平均后的坐标转回 binary32。
反解使用的加权线性矩阵采用相同累计政策，归一化后的系数仍是 binary32 输入。
保留正权重筛选、EPSILON 总量条件和逐 influence 的坐标空间/仿射计算。

逻辑顶点到绑定增量满足 `O=B_linear*(P-S)`，已有 offset 的编辑满足
`O_new=O_old+B_linear*(P_after-P_before)`。减法可能超出 binary32，但缩放后
或加回已有 offset 后的最终结果可以表示；在 binary64 完成这些运算后再检查
最终 offset。平移不参与增量；显式局部坐标时 B_linear 为单位矩阵。

这些是既有线性方程与归一化定义的数值修复，不改变皮肤/linked 所有权、
权重约束、数据布局、API/profile 或最终失败类型。正常数据的末位舍入可能改变。
不据此声称全部矩阵乘法、高条件数、混合或空间转换在任意极端值上精确；
保留每项仿射结果与最终加权矩阵系数必须可表示的现有边界。
